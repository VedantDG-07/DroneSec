Unsecured Mode Traffic Observation

When Encryption is detached, click Transmit via Pipeline. In Wireshark, select the captured HTTP packet and choose Follow → TCP Stream. The JSON payload {"command": "...", "parameters": ...} is directly readable in plain ASCII/UTF-8 text over the network.

Protected Mode Traffic Observation

When Encryption is attached, click Transmit via Pipeline. In Wireshark, the TCP stream shows Base64-encoded ciphertext, 12-byte iv, and 16-byte auth_tag. The underlying command payload is cryptographically confidential and protected against tampering.

Detailed exercise guide available in repository: docs/wireshark-practical.md (Traffic script: python -m backend.scripts.wireshark_lab)
Cyberattack Scenarios
ATK-01 Unauthorized Injection
Submits commands with missing/invalid Bearer tokens. Tests operator authentication.
ATK-02 Message Tampering
Injects bit-flipped ciphertext or manipulated coordinates. Tests AEAD authentication tag verification.
ATK-03 Command Replay
Replays captured sequence frames at future timestamps. Tests anti-replay sliding window.
ATK-04 Sender Identity Spoofing
Crafts counterfeit GCS identity with unauthorized credentials. Tests sender authorization checks.
ATK-05 Malformed Fuzzing
Submits out-of-range coordinates, corrupt types & invalid enums. Tests strict Pydantic validation.
ATK-06 Bounded DoS Burst
Saturates link capacity exceeding token-bucket capacity. Tests rate limiter throttling (HTTP 429).
